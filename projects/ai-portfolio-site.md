## 개요

취업 준비 과정을 정리하기 위해 AI 코딩 도구 **Claude Code**와 대화하며 이 포트폴리오 사이트를 만들었습니다. 코드를 직접 짜는 대신 원하는 페이지 구성, 색상, 기능을 말로 설명하고 결과를 확인하며 수정을 요청하는 방식으로 진행했습니다.

- 사이트: [wltjd2764-ops.github.io/portfolio](https://wltjd2764-ops.github.io/portfolio/)
- 소스 코드: [github.com/wltjd2764-ops/portfolio](https://github.com/wltjd2764-ops/portfolio)

## AI로 구현한 것

- **사이트 구조:** 소개 · 학교생활 · 자격증 · 수상·경력 · 프로젝트 기록 · 관심사 · 건축 뉴스 페이지
- **디자인:** 컬러칩(#898989 · #D9D9D9 · #FF4D4D · #4DFFBC)을 주고 화이트 바탕에 맞춰 적용, 모바일 · 다크모드 대응
- **건축 뉴스 자동 수집:** 건설경기 · 수주 · 금리·PF·정책 · 건축·설계 · 원전·특수건축 기사를 매일 아침 7시에 자동으로 모아 보여주는 기능 (GitHub Actions)
- **배포:** GitHub Pages로 공개, 수정할 때마다 자동 반영
