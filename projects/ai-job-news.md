## 개요

취업 준비를 위해 **희망 공기업과 관련된 건설 · 에너지 뉴스를 매일 아침 자동으로 모으는** Google Apps Script를 만들었습니다. 네이버 검색 API로 키워드별 기사를 가져와 구글 스프레드시트에 정리합니다.

## 수집 키워드와 이유

| 키워드 | 왜 보는가 |
| --- | --- |
| LH 공공주택 발주 | LH가 어느 지역에 어떤 규모로 주택 사업을 내놓는지 흐름 파악 |
| 한수원 해외수주 | 체코 등 해외 원전 수주전 진행 상황 — 한수원 면접 필수 지식 |
| 한수원 SMR 투자 | SMR을 사업화하고 투자하는 경영 전략 관점의 기사 |
| 한전 송전망 건설 | 한전의 가장 큰 인프라 과제인 대규모 전력망 확충 동향 |
| 캠코 국유지 개발 | 노후 국유 건물을 리모델링 · 개발해 수익을 내는 핵심 사업 |
| 캠코 제로에너지 건축 | 공공개발에 필수가 된 제로에너지 건축물(ZEB) 적용 방식 |
| 공공공사 BIM 의무화 | 타깃 기업들이 BIM 전면 도입을 어떻게 준비하는지 |
| 건설업 ESG 경영 | 폐기물 재활용, 친환경 자재, 안전보건 관리에 대한 기업별 대응 |

키워드별로 1건씩, 하루 8건의 기사를 가져오고 **매일 아침 8시에 자동 실행**되도록 트리거를 설정했습니다.

## 시행착오 · 배운 점

- 처음에는 **잡알리오(공공기관 채용정보) API**로 채용공고를 자동 정리하려고 API 키까지 발급받았지만, 국가기관 보안 정책 때문에 Apps Script 환경에서는 접근할 수 없었습니다.
- 그래서 방향을 바꿔 **네이버 검색 API로 기업 동향 뉴스를 수집**하는 방식으로 완성했습니다.
- 이 아이디어는 이 포트폴리오 사이트의 [건축 뉴스](news.html) 자동 수집 기능으로 이어졌습니다.
