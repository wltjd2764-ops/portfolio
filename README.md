# Portfolio

건축 전공 취업 준비 포트폴리오 — https://wltjd2764-ops.github.io/portfolio/

| 페이지 | 파일 |
| --- | --- |
| 소개 | `index.html` |
| 자격증 | `certifications.html` |
| 경험 | `activities.html` |
| 건축 뉴스 | `news.html` (+ `data/news.json`) |

- 공통 메뉴·이름: `assets/js/main.js`의 `SITE`
- 디자인: `assets/css/style.css`
- 뉴스: `scripts/fetch_news.py`가 Google 뉴스 RSS에서 수집하고, GitHub Actions가 매일 07:00(KST)에 실행 후 배포
- 원본 자료: `_자료/` 폴더 (git에 올라가지 않음)
